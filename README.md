# Mapa możliwości klienta — MentalWay

Standalone strona instruktażowa pokazująca 7 poziomów ścieżki rozwoju klienta
MentalWay — od darmowej wiedzy (social media, newsletter, WayUp) po
indywidualny mentoring (Life Spectrum Mentoring).

Jeden plik `index.html`, bez zależności poza fontami Google (Bebas Neue + Inter).
Paleta ciemny editorial (`#0d0c09` + złoto `#c9a820`) zgodna z mentalway.pl.

Przeznaczenie: osadzenie jako strona MW + link w mailu po zakupie.

## Poziomy

1. Darmowa wiedza — social media, newsletter, WayUp (wybrane szkolenia 30 dni gratis)
2. Materiały szkoleniowe — książki, Dziennik Behawioralny, VOD, audio, audiobooki
3. Społeczność — Karta MMC (Discord Mentalwayandia + Dashboard)
4. Wyjazdy stacjonarne — Mental Shelter (warsztaty, Majówki, wakacje tematyczne)
5. Programy grupowe online z mentorem — Personal Branding & GLSM (wymagają MMC)
6. Konsultacje 1:1 z Michałem — wejście bezpośrednie
7. Life Spectrum Mentoring — indywidualnie, długoterminowo, wejście bezpośrednie
